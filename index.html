How to Deploy to Vercel

Choose between the Vercel Dashboard or the CLI.

01

Option A: Vercel CLI

Run these quick commands in your terminal:

npm i -g vercel
vercel

Follow the prompt defaults and your site goes live instantly.

02

Option B: Git Push

Push your repository to GitHub, GitLab, or Bitbucket:

git add .
git commit -m "init"
git push

Import the repository in vercel.com/new.
